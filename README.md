# ระบบตรวจจับรถบรรทุก - คลุมผ้าใบ (ต้นแบบ)

เว็บแอปสาธิตสำหรับตรวจจับรถบรรทุกที่ผ่านกล้อง วิเคราะห์ป้ายทะเบียน และสถานะการคลุมผ้าใบ
(คลุม / ไม่คลุม / คลุมไม่เรียบร้อย) จากไฟล์วิดีโอ `trucks.mp4`

## วิธีรัน

```
pip install -r requirements.txt
python app.py
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:5000`

ครั้งแรกที่รัน ระบบจะวิเคราะห์วิดีโออัตโนมัติและสร้างไฟล์ `static/detections.json`
พร้อมรูปตัวอย่างใน `static/thumbs/` ถ้าต้องการวิเคราะห์ใหม่ (สุ่มค่าใหม่) ให้ลบไฟล์
`static/detections.json` แล้วรันใหม่ หรือรัน:

```
python detector.py
```

## อะไรจริง อะไรจำลอง (สำคัญ อ่านก่อนนำไปใช้งานจริง)

ระบบนี้ตั้งใจให้เบา ใช้ OpenCV อย่างเดียว ไม่มีโมเดล AI/Deep Learning ดังนั้น:

**ส่วนที่ตรวจจับจริงจากวิดีโอ:**
- **ตำแหน่งรถในทุกเฟรม (กรอบเลื่อนตามรถ)** — กล้องตั้งนิ่ง จึงสร้างภาพพื้นหลังเปล่าจากค่ามัธยฐาน
  (median) ของทุกเฟรม แล้วเทียบแต่ละเฟรมกับพื้นหลังเพื่อหาส่วนที่เป็นรถ (background subtraction)
  พร้อมตัดเงารถบนถนนออกบางส่วน
- **แยกรถแต่ละคัน (tracking)** — จับคู่กรอบของเฟรมติดกันด้วยการซ้อนทับ/ระยะห่าง ทำให้รถแต่ละคัน
  มีกรอบของตัวเองที่เลื่อนตามรถไปตลอดทาง หน้าเว็บจะ interpolate กรอบระหว่างเฟรมให้เคลื่อนที่ลื่น
- **จังหวะที่บันทึกรถลงรายการ** — เฟรมที่รถอยู่ใกล้กล้องที่สุดโดยยังอยู่ในภาพทั้งคัน

**ส่วนที่จำลอง (mock) เพื่อสาธิต UI:**
- **เลขป้ายทะเบียน** — กำหนดไว้ต่อคัน ไม่มีการอ่าน OCR จริง
- **สถานะคลุมผ้าใบ** — วิธีประมวลผลภาพแบบง่ายแยกผ้าใบออกจากกองหินที่ไม่ได้คลุมได้ไม่แม่นยำ
  จึงกำหนดสถานะของรถแต่ละคันในคลิปนี้ไว้ใน `FIXED_PLATE_STATUS` (ตรวจด้วยตาเทียบกับวิดีโอ)
  — **ถ้าต้องการความแม่นยำจริง ต้องฝึกโมเดลจำแนกภาพ (image classifier) ด้วยข้อมูลตัวอย่างจริง**

ถ้าเปลี่ยนคลิป ให้แก้ `FIXED_PLATE_STATUS` ใน `detector.py` ให้ตรงกับรถในคลิปใหม่ตามลำดับที่ปรากฏ
แล้วรัน `python detector.py`

## โครงสร้างไฟล์

- `detector.py` — pipeline วิเคราะห์วิดีโอด้วย OpenCV, สร้าง `static/detections.json`
- `app.py` — Flask server เสิร์ฟหน้าเว็บและ API
- `templates/index.html`, `static/css/style.css`, `static/js/app.js` — หน้าเว็บ
- `static/video/trucks.mp4` — วิดีโอตัวอย่าง
- `static/thumbs/` — รูป thumbnail ของรถแต่ละคันที่ตรวจพบ
