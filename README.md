# ระบบตรวจจับรถบรรทุก - คลุมผ้าใบ (ต้นแบบ)

เว็บแอปสาธิตสำหรับตรวจจับรถบรรทุกที่ผ่านกล้อง วิเคราะห์ป้ายทะเบียน และสถานะการคลุมผ้าใบ
(คลุม / ไม่คลุม / คลุมไม่เรียบร้อย) จากไฟล์วิดีโอ `trucks.mp4`

## วิธีรัน

```
pip install -r requirements.txt
python app.py
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:5000`

ครั้งแรกที่รัน ระบบจะวิเคราะห์วิดีโออัตโนมัติและสร้างไฟล์ `static/detections.json`
พร้อมรูปตัวอย่างใน `static/thumbs/` ถ้าต้องการวิเคราะห์ใหม่ (สุ่มค่าใหม่) ให้ลบไฟล์
`static/detections.json` แล้วรันใหม่ หรือรัน:

```
python detector.py
```

## อะไรจริง อะไรจำลอง (สำคัญ อ่านก่อนนำไปใช้งานจริง)

ระบบนี้ตั้งใจให้เบา ใช้ OpenCV อย่างเดียว ไม่มีโมเดล AI/Deep Learning ดังนั้น:

**ส่วนที่ตรวจจับจริงจากวิดีโอ:**
- **เวลาที่รถแต่ละคันผ่านกล้อง** — วัดจากพลังงานความเคลื่อนไหวจริงในแถบล่างของภาพ
  (motion energy) แล้วหาจุดพีค (peak) ซึ่งเป็นเทคนิค "tripwire" ที่ใช้กันจริงในระบบนับรถ
- **ตำแหน่งกรอบสี่เหลี่ยม (bounding box)** — หาจาก frame-difference mask จริง โดยเลื่อนหน้าต่าง
  ขนาดคงที่ไปหาบริเวณที่มีความเคลื่อนไหวหนาแน่นที่สุด (sliding-window search) ซึ่งจะได้ตำแหน่ง
  รถที่ใกล้กล้องที่สุด ณ ขณะนั้นจริง ๆ

**ส่วนที่จำลอง (mock) เพื่อสาธิต UI:**
- **เลขป้ายทะเบียน** — สุ่มข้อความรูปแบบป้ายไทย ไม่มีการอ่าน OCR จริง
- **สถานะคลุมผ้าใบ** — ทดลองใช้ heuristic ทางภาพหลายแบบแล้ว (ความหนาแน่นของเส้นขอบ,
  ความหลากของสี, ความเป็นลอนของขอบด้านบนกองสินค้า) แต่ไม่สามารถแยกผ้าใบลายตาหมากรุก/ลายทาง
  ออกจากกองหินที่ไม่ได้คลุมได้อย่างแม่นยำด้วยวิธีง่าย ๆ เพราะภาพมีความหลากหลายสูง
  จึงจำลองผลด้วยการสุ่ม (แต่คุมสัดส่วนให้มีครบ 3 กลุ่ม) — **ถ้าต้องการความแม่นยำจริง
  ต้องฝึกโมเดลจำแนกภาพ (image classifier) ด้วยข้อมูลตัวอย่างจริง**

หน้าเว็บมีข้อความหมายเหตุนี้แสดงอยู่ด้านล่างของหน้าด้วย เพื่อไม่ให้เข้าใจผิดว่าเป็นผลตรวจจับจริง 100%

## โครงสร้างไฟล์

- `detector.py` — pipeline วิเคราะห์วิดีโอด้วย OpenCV, สร้าง `static/detections.json`
- `app.py` — Flask server เสิร์ฟหน้าเว็บและ API
- `templates/index.html`, `static/css/style.css`, `static/js/app.js` — หน้าเว็บ
- `static/video/trucks.mp4` — วิดีโอตัวอย่าง
- `static/thumbs/` — รูป thumbnail ของรถแต่ละคันที่ตรวจพบ
